## 2. 逐项说明

- ckpt-4665 唯一未过的是情绪：151/209 = 0.7225，差门槛 0.43 个点，约 1 条样本。
- 情绪随步数：0.5981 → 0.7177 → 0.7225。512 到 2048 涨 12 个点，2048 到 4665 只多认对 1 条，已平。
- 文本质量继续改善：BLEU-4 0.1270、ROUGE-L F 0.3018 均超基线，长度比 1.0262 最接近 1。
- 512 的长度是双峰：中位 70 字、20 条 >500 字、9 条 >1500 字，含整句复读；2048 起收住，4665 剩 2 条截断（均为 1200 token 上限，finish=length）。

## 3. 错误结构（ckpt-4665）

- anxiety 预测 81 / gold 64，继续吸收近邻；
- mixed：gold 20 条仅认对 1 条，9 条判 anxiety、4 条判 anger；
- care：gold 5 条全部判 anxiety；
- disgust：零预测；
- 与 512、2048 同型。不是训练不足，是标签先验与决策边界问题，继续加步数改不动。

## 4. 口径与限制

1. 本次训练总长 1536，E01-B 是 2048，不是同口径。1536 是独立脚本显存管理下的工程取舍，不是 8G 硬件上限（E01-B 在 2048 下峰值 allocated 3.83G / reserved 4.10G）。
2. 训练集关系：E01-B 的 16,192 是本次 18,657 的严格子集。D0.3 账本 18,657 = 4 隔离 + 508 精确去重 + 16,312 train + 1,833 dev；D0.4.3 再扣 120 条 completion 超长，得 16,192。我们多训 2,465 点，其中 1,833 点是 E01-B 的内部 Dev。
3. 因此 E01-B 报告的 Dev 情绪 65.36%、画像 micro-F1 0.4223 与本报告任何数字都不可比；唯一可横比的是同一 209 点上的 E01-B 基线 0.7368。E01-B 的 209 点 0.7368 与它 Dev 的 65.36 是两个集合，不能混用。
4. 本报告只覆盖稠密半。画像半由训练侧单独产出，提交时用 `../tools/e03b_merge_submission.py` 合并。
