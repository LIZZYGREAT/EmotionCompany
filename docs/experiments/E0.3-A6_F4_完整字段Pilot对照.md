# E0.3-A6 F4：完整字段名 Pilot 对照

## 目的与边界

验证将 F3 的缩写字段改成完整字段名，是否有助于模型学习情绪与用户画像输出。F4 将监督目标写成：

```text
Emotion=<emotion>
Personality=<labels or ->
Interests=<labels or ->
Style=<labels or ->
Response=<full reply>
```

字段顺序、官方标签集合、标签顺序、空画像表示和回复正文语义保持一致。该试验使用独立的 F4 协议、Prompt、序列化器和严格解析器；P0/T1 历史选择不变。没有运行 Full 训练，也没有修改受保护数据或官方协议文件。训练和推理产物均保存在未跟踪的 `outputs/` 下。

## 结果

### Fast Dev：画像指标改善，但门槛仍未通过

| 指标 | F3 1,024 条 | F4 1,024 条 | 变化 |
|---|---:|---:|---:|
| 严格格式解析率 | 100% | 100% | 持平 |
| 情绪准确率 | 49.38% | 52.50% | +3.12 个百分点 |
| 产生非空画像预测的样本数 / 160 | 4 | 6 | +2 |
| 33 类画像 micro F1 | 0.0153 | 0.0300 | +0.0147，约为原来的 1.96 倍 |
| 画像 TP / FP / FN | 2 / 2 / 256 | 4 / 5 / 254 | TP +2，FP +3，FN -2 |
| 画像 micro precision | 0.500 | 0.444 | -0.056 |
| 三个画像维度同时精确匹配 | 36.25% | 36.25% | 持平 |
| 最常见情绪预测占比 | 48.75% | 45.00% | -3.75 个百分点 |

按维度看，F4 性格 traits micro F1 从 0 升到 0.0196，兴趣从 0.0678 升到 0.0984，交流风格仍为 0。完整字段版开始输出少量性格和风格标签，但总体画像预测依旧稀疏。

F4 Fast 门槛未通过：160 条中至少 16 条应产生非空画像，F4 只有 6 条；画像 TP 门槛为 5，F4 得到 4。严格解析、精确率、情绪准确率、FP 上限和情绪集中度检查均通过。F3 与 F4 两组都没有通过完整 Fast 质量门槛。

这些指标是固定 160 条队列上的本地代理指标。虽然两组采用同一批 Train 和评测 ID、同一训练步数和种子，但目前只有一次 F4 运行，不能据此得出稳定泛化结论。

### Full-generation Smoke：F4 协议门槛通过

F4 的 32 条 Smoke 全部通过严格解析、官方 Schema 校验、Fast/Full 字段前缀 token 与语义等价、非空回复和 EOS 检查；五项均为 100%，Smoke 门槛通过。F3 扩展组在同一 32 条上也通过全部协议门槛。

F4 的回复本地代理分数略低于 F3 扩展组：字符 BLEU-4 为 9.63（F3 11.35），字符 ROUGE-L macro F1 为 0.2202（F3 0.2325）；平均回复长度为 260.5 字符（F3 240.3）。这些是 32 条上的本地代理，不是官方评分。当前结果说明完整字段没有破坏生成协议，但不能说明回复质量提高。

### SFT Dev Loss

F4 的 SFT Dev loss 从 step 32 的 `2.1770` 降至 step 256 的 `1.9456`。同配置规模的 F3 扩展组 step 256 为 `2.0011`。F4 的 loss 较低，但这项差异不能替代固定 Fast Dev 上未通过的画像质量门槛。

- F4 训练资产 CPU 预检通过：Train/Dev 为 1,024/256 条，样本 ID 与 F3 扩展组一致，序列长度在配置上限内。
- GPU 单步 Dry Step 通过，loss 和梯度有限；256 步训练在 step 64 检查点暂停后成功恢复并完成。

- F4 评测预检通过，生成阶段未读取 References。
- Fast 160 完成 160/160 条；Smoke 32 完成 32/32 条。
- 定向单测 `tests/test_e03_a6_f3_pilot_eval.py`、F4 协议、A6 协议、Runner、数据和训练契约共 61 项通过；评测脚本语法编译和 `git diff --check` 通过。
- Full 训练未运行，清单保持 `not_authorized_not_run`。

## 结论

完整字段名在这次配对 Pilot 中显示出正向信号：SFT Dev loss 更低，情绪准确率提高，画像 micro F1 约翻倍，画像 TP 增加；严格格式和 Full-generation Smoke 协议保持稳定。与此同时，画像预测仍非常稀疏，F4 未达到 Fast 门槛，画像精确率和 Smoke 回复代理分数也略降。

因此，F4 值得保留并进行一次有界复现或针对画像稀疏的诊断；当前证据不足以启动 Full 训练。下一次比较仍应使用相同固定 ID 和门槛，并优先确认画像输出率能否稳定提高。
