## 四、基线比较与结论

Dev 224 与 E01-B Full Fast-only 使用同一固定 ID 集。E01-B Full 基线画像 Micro-F1 为 `0.4258`，TP/FP/FN 为 `142/152/231`，Precision/Recall 为 `0.4830/0.3807`；F4 Step 2,048 为 `0.1029`，TP/FP/FN 为 `21/14/352`，Precision/Recall 为 `0.6000/0.0563`。F4 少报误报但漏报远多于基线，画像 Recall 是主要差距；情绪 Accuracy `0.6786` 也低于基线 `0.6920`。这是当前 224 点 Fast-only 证据，不外推为 F4 永远无法改善。

**决策：** F4 Full 的数据、训练恢复、检查点保留、协议终止和 Fast-only 评测工程链路可用；画像质量仍明显落后基线。记录 `continuation_recommendation=stop`，不继续从 2,048 到 4,048，不替换 E01-B Full。没有完整 1,833 Dev 或官方 Val 结果。
