# E03-B：T1 历史裁剪的证据损失（描述性统计）

> 口径：官方 Val，2354 个预测点；P0/F2/T1，P=1280；Qwen3-1.7B 的 tokenizer。
> 性质：描述性统计，不是因果结论；未与 Full B 的逐样本预测交叉。
> 日期：2026-11-03。

## 一、要回答什么

T1 是「最近连续完整消息后缀」：先保最后一条用户消息，再逐条向前加，加不进 P=1280 就停。那么在这批 Val 上，到底有多少点被截、截掉多少、被截掉的段落里有没有画像证据。

## 二、方法

1. 把 `val_public.jsonl` 的 900 段对话按 `prediction_points` 展开成 2354 个点，每点的 history 取到目标用户消息为止。
2. 用仓库 `src/shared/prompting.py` 的 `build_messages`、`encode_inference_prompt`、`select_recent_complete_suffix` 计算真实 token 与 T1 选择结果，不另写一套近似实现。
3. 「证据」用关键词规则：每个画像标签对应一组中文关键词，规则在 Train 上做过召回体检后冻结，套到 Val 时不改。
4. 一个标签算「乐观可救」，要求三件事同时成立：该点 Gold 画像非空；关键词按对应维度和标签命中；命中只出现在被裁掉的段落、保留段里没有。

## 三、结果

| 指标 | 值 |
|---|---:|
| 预测点 | 2354 |
| 被截断点 | 584（24.81%） |
| 平均完整 prompt token | 1079.1 |
| 平均保留 token | 869.4 |
| 平均丢弃 token | 209.7 |
| 被截点平均丢消息条数 | 8.0 |
| 最小集合即超 P | 0 |

乐观可救：**81 个点**、**96 个标签命中**。分母两种口径：81/584 = 13.9%（被截点内），81/2354 = 3.4%（全量）。分维度命中数：style 39、personality_traits 34、interests 23，这几个数都是标签命中数，不是点数。

## 四、规则质量

关键词规则在 Train 上的召回约五成：conservative 0.531、high_conscientiousness 0.659、introverted 0.537，open 只有 0.085。也就是说它既会漏掉真实证据，也会误命中一些句子，误差方向不定。

所以 81 只能当量级参考，不能称为上界，更不能写成「能提升多少」。

## 五、结论

- **证据支持**：T1 确实裁掉了相当一部分历史，四分之一的点看不到完整历史，重的丢八条消息。
- **证据不支持**：不能据此说画像漏报是裁剪造成的。要回答这个，必须有 Full B 的逐样本预测，把「被截」和「画像全漏」放在同一张表里。
- **证据不足**：证据规则精度不够，乐观可救数只能作量级参考。
