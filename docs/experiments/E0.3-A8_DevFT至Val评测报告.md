# E03-A8 DevFT 至 Val 评测报告

## 结论

从 A8-V2 P Step 4,048 检查点恢复权重、AdamW 与 scheduler，在 D0.3 Dev 上完成一轮续训，再对 D0.3 Val 进行无标签生成。完整 Val 的画像 33 标签 Micro-F1 为 **0.4678**；排除 A2 曾精确探索的 209 个点 ID 后，2,145 点子集 Micro-F1 为 **0.4722**。

所有指标均为本地代理分数，不是官方成绩。排除 A2 的 209 个点 ID 后，剩余样本仍与那 78 个已探索对话共享上下文。Dev 已作为训练数据使用，不能再用于该模型的独立泛化评估。

## Val 预测与评分

生成前冻结 2,354 条只含 `id` 与 `history` 的输入。预测 JSONL SHA-256 锁定后才读取 D0.3 Val Gold。全部 2,354 条都生成了 EOS；2,352 条通过严格格式解析，另 2 条因标签顺序不规范而在固定分母评分中按空画像处理。

| Cohort | 点数 | 严格有效 | TP / FP / FN | Precision | Recall | Micro-F1 | Macro-F1 | Conversation bootstrap 95% 区间 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 完整 Val | 2,354 | 2,352 | 1,335 / 1,254 / 1,784 | 0.5156 | 0.4280 | **0.4678** | 0.3128 | 0.4385–0.4928 |
| A2 曾探索的精确点 ID | 209 | 209 | 91 / 116 / 141 | 0.4396 | 0.3922 | 0.4146 | 0.1777 | 0.3278–0.4905 |
| 排除 A2 精确点 ID | 2,145 | 2,143 | 1,244 / 1,138 / 1,643 | 0.5223 | 0.4309 | **0.4722** | 0.3181 | 0.4457–0.4990 |

三维画像表现如下：

| Cohort | 维度 | TP / FP / FN | Micro-F1 | Macro-F1 |
|---|---|---:|---:|---:|
| 完整 Val | Personality | 466 / 472 / 677 | 0.4479 | 0.1902 |
| 完整 Val | Interests | 386 / 117 / 257 | 0.6736 | 0.5794 |
| 完整 Val | Style | 483 / 665 / 850 | 0.3894 | 0.1334 |
| 排除 A2 精确点 ID | Personality | 429 / 433 / 644 | 0.4434 | 0.1892 |

Interests 相对较好；Style 的 Macro-F1 和召回仍低，且假阳性较多。完整 Val 上模型输出 1,254 个假阳性并漏掉 1,784 个 Gold 标签，仍有明显召回和细粒度标签问题。

本轮未生成 P4048 在同一 Val ID 集上的配对预测，因此不报告可归因于 DevFT 的增益量。完整 Val 的绝对分数和排除 A2 精确点 ID 的分数可用于本次观察；它们不证明官方 Test 泛化。
