# E03-A8 困难样本 Replay 实验结果

> 本报告记录 E03-A8 P 分支的一次困难样本挖掘与分阶段 Replay。所有质量分数均为项目内 local_proxy，不是官方赛事成绩。运行原始清单和预测保存在 Git 忽略目录 outputs/training/E03-A8-REPLAY/E03-A8-REPLAY-20261108-02/。

## 1. 结论

Run E03-A8-REPLAY-20261108-02 完成候选抽样、父模型 Greedy 预测、错误挖掘、冻结调度、Replay128 和配对 val_gate 评分。Replay128 的画像 Micro-F1 从同集 P4504 的 0.491393 降至 0.413252，TP 减少 77；Personality 与 Style 两维 F1 分别下降 0.155206 和 0.072753，Pilot 质量门失败。
