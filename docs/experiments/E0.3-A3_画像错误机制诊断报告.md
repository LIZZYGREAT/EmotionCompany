# E03-A3 画像错误机制诊断报告

> 日期：2026-11-04。范围：阶段 0/1 的 CPU 只读诊断、G1 决策和冻结短程评测集合；未训练、未加载模型、未运行推理。Full Dev 曾用于项目开发，因此本报告中的 Dev 指标是 `development_proxy`，不是未触碰测试集。

## 结论

E01-B 的完整 Dev 显示出跨会话重复的短历史画像漏报信号：原始历史 1–4 条时，Gold 非空点中有 `105/146 = 71.92%` 的预测画像三维全空；5 条以上对应 `322/1,027 = 31.35%`。按 Gold 标签数分层、按三个维度拆分后，短历史召回仍低于长历史。Train 中也有足够的短历史正负样本支持一次温和、可证伪的采样候选。

这个结果支持“值得进行一次低成本短程验证”，不证明历史长度本身造成了错误。原始长度与证据量、目标轮次、标签密度相关；置信区间只描述按会话聚类后的抽样波动，不是因果检验。即使短历史的 230 个 FN 全部无新增 FP 地恢复，整体 Micro-F1 上限也只有 `0.4873`，单靠该子组达不到 `0.50`。

**首选候选（阶段 0/1 决策时尚未实现；截至 2026-11-05 已完成工具实现，未运行）**：对有效 SFT Train 的 16,192 条样本做温和混合采样。每轮抽样约 50% 来自全量 Train 的自然均匀抽样，另 50% 来自原始历史 1–4 条样本；短历史池按 Gold 三维全空/非空各占一半抽样。标准 completion-only loss、P0/F2/T1、模型、优化器配置与生成协议保持一致。候选必须与从同一个 E01-B Adapter 开始的 128-step 均匀抽样 Control 配对比较。

本节记录阶段 0/1 诊断完成时的状态。2026-11-05 用户明确授权阶段 3 短程对照后，阶段 2 已实现独立采样器、短程 runner 和冻结集评测器；CPU 资产审计通过。GPU dry-step、训练与生成仍未运行，当前可执行命令和资源门槛见[阶段 2 与短程运行准备](E0.3-A3_阶段2与短程运行准备.md)。

原始短历史组更现实地对“新增 FP/每恢复 TP”作敏感性测算：

| 假设恢复原始短组 FN | 新增 FP/恢复 TP=0 | 0.5 | 1 |
|---:|---:|---:|---:|

## 5. G1 决策与短程设计

### G1：通过，支持一个候选

证据包含 Dev 的漏报分子/分母、256 个短历史组会话，以及 Train 中 2,629 条有效短历史 SFT、2,321 个对话，其中 Gold 全空 1,274、Gold 非空 1,355。全 Dev 与 Train 短历史的 Gold 空比例分别为 48.2% 与 48.5%；Train 提供可用于平衡正负样本的两类短历史样本。所有 33 标签的交叉计数保存在聚合 CSV。

短程实验的可证伪预测：如果短历史采样值得继续，Candidate 在冻结集合上相对同初始化、同训练步数的 Control 应增加 TP；Gold 全空点不应出现大幅 FP 恶化；同时报告画像 Micro-F1、TP/FP/FN、Raw 有效率，以及情绪/回复的回归指标。候选失败、差异很小或 FP 明显增加时停止，不扩大步数。
