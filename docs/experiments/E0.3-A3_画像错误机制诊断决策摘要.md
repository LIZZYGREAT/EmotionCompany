## 发现

- Full Dev 1,833 点复算 E01-B：TP/FP/FN=`1130/1271/1821`，画像 Micro-F1=`0.42227`、Macro-F1=`0.27000`。
- 原始历史 1–4 条的 282 点中，Gold 非空点有 `105/146 = 71.9%` 预测画像全空；5 条以上为 `322/1027 = 31.4%`。短历史标签 Recall `19.3%`，长历史 `40.3%`；按会话聚类 Bootstrap 的短减长 95% 区间为 `[-0.273, -0.146]`。

- 该关联不证明因果。短组 230 个 FN 全部无新增 FP 地恢复，整体 Micro-F1 也仅达 `0.4873`；达到 0.50 至少需要新增 278 TP。
- E03-A1 `label_value_x2` 的全量 Dev Micro-F1 为 `0.38391`，不作续训基线。候选从 E01-B Adapter 开始。
