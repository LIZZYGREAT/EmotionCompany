## 4. 实现与安全边界

- 训练更新使用 TRL `SFTTrainer` 和 D0.4.3 `SFTDataCollator`。运行时核对 `skip_prepare_dataset=true`、`max_length=null`、`packing=false`、`padding_free=false`，并逐批比较 `input_ids`、`attention_mask`、`labels`。
- D0.4.3 的 Completion 监督可能在模板 EOS 后包含尾随空白 Token；预检只要求受监督 Completion 中包含锁定 EOS，不要求 EOS 是最后一个 Token。Labels 不重建、不手工 shift。
- E01-A 和 E01-B 的 `init_adapter`、`resume_from_checkpoint` 均为空；A 的 one-step proof 必须来自不同 Run ID，B 配置只允许 preflight。
- Adapter 推理必须显式启用并同时匹配 Base 权重 SHA、Adapter 权重 SHA 和可选 Adapter 配置 SHA；默认配置没有启用 Adapter。Scorer 对 E00 仍要求无 Adapter，对 E01 快照核验 Base 与 Adapter 双身份。
- Base 权重只读；训练产物、Raw 生成和预检 JSON 均写入忽略目录 `outputs/training/`。没有修改官方数据、Schema、P0、`start.sh` 或默认推理配置。

第一次预检 `E01-A-preflight-20261027-001` 暴露了“EOS 必须为最后 Token”的过严假设，已修正并增加回归。随后 one-step Run `E01-STEP-20261027-220539` 暴露 NF4 检查漏传 `quantization.enabled=true`，也已修复；之后 `E01-STEP-20261027-221949` 成功生成 proof，Loss 为 `4.4916`，LoRA 更新与 Base 不变检查均通过。A Run `E01-A-20261027-222025` 完成训练、诊断、Adapter 保存和重载，但在 `del trainer, model` 后仍从 `trainer.e01_data_path_facts` 组装 Manifest，导致终结阶段失败。现已在释放前快照 Trainer 数据路径证据，并同时释放 Callback/参数对旧模型的引用；新增回归覆盖快照生命周期。失败 Run 保留，规范复跑必须使用新 Run ID。

在有可用 CUDA/BF16 的主机上，从新 Run ID 继续。预检状态必须为 `passed`；若 one-step 失败或没有生成 `step_proof.json`，不要执行 train：

```bash
PREFLIGHT_RUN_ID="E01-A-preflight-$(date +%Y%m%d-%H%M%S)"
python -m src.training.training_sft \
  --config configs/training/e01_a.yaml \
  --mode preflight \
  --run-id "$PREFLIGHT_RUN_ID"

PREFLIGHT_STATUS=$(python -c 'import json,sys; print(json.load(open(sys.argv[1]))["status"])' \
  "outputs/training/$PREFLIGHT_RUN_ID/preflight.json")
if [ "$PREFLIGHT_STATUS" = "passed" ]; then
  STEP_RUN_ID="E01-STEP-$(date +%Y%m%d-%H%M%S)"
  STEP_PROOF="outputs/training/$STEP_RUN_ID/step_proof.json"
  A_RUN_ID="E01-A-$(date +%Y%m%d-%H%M%S)"
  if python -m src.training.training_sft \
    --config configs/training/e01_a.yaml \
    --mode one-step \
    --run-id "$STEP_RUN_ID"; then
    if [ -s "$STEP_PROOF" ] && python -c 'import json,sys; d=json.load(open(sys.argv[1])); sys.exit(0 if d.get("status")=="passed" else 1)' "$STEP_PROOF"; then
      python -m src.training.training_sft \
        --config configs/training/e01_a.yaml \
        --mode train \
        --run-id "$A_RUN_ID" \
        --one-step-proof "$STEP_PROOF"
    else
      echo "one-step proof missing or not passed; train was not started" >&2
    fi
  else
    echo "one-step failed; train was not started" >&2
  fi
else
  echo "preflight status is $PREFLIGHT_STATUS; stop" >&2
fi
```
