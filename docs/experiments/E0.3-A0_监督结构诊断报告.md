## 6. 证据边界与后续候选

### 已验证事实

- 回复正文占全体明确监督 Token 的 79.2621%；Profile 对象占 8.8924%；情绪值占 1.0569%；公共结构、EOS 和混合 Token 分别占 6.2460%、0.5678% 和 3.9747%。所有监督 Token 均有唯一归属。
- Gold 非空画像样本的 Profile Token 平均数高于 Gold 三维全空组；三个维度的空/非空条件组也有不同 Profile Token 数。维度组样本会重叠。
- `trimmed_fit` 与长 Completion 组的回复 Token Share 更高。这是相关性，不等同于 T1、Loss 或梯度造成差异。
- 输入 Hash、Tokenizer/Template 身份、重建序列 ID、Label Mask、EOS、Full B Base/Adapter 文件指纹均通过核验。

### 尚不能判断

- 因 GPU 不可用，A0 没有观测 Full B 的字段 CE，也没有验证手工字段 CE 与模型原生 `output.loss` 的一致性。不能根据 Token 数推断字段 Loss、梯度范数、梯度方向、训练阶段的梯度历史或比赛分数收益。
- 即使后续得到字段 CE，平均 CE 与 CE 总和贡献仍不能代替梯度贡献；需要单独的梯度研究才能讨论任务间梯度冲突。
- Tokenizer 对固定空 `memory_refs` 和 Profile 结构没有产生独立可归属 Token；需要在任何字段加权方案中保留并明确处理结构/边界桶。

### A1 待验证方向（不构成立项或实现批准）

1. 在相同样本和训练配置下，对照原始 Token 平均与“情绪、画像、回复字段均值”的目标；结构、EOS 和 `boundary_mixed` 权重保持显式固定。只有 GPU CE 门禁通过后再确定权重定义。
2. 若字段级对照显示 Profile 确有目标尺度问题，再比较按完整 Profile 对象加权与按三个画像维度聚合；同时监测 FP、回复和情绪变化，避免仅提高空数组/结构监督。
