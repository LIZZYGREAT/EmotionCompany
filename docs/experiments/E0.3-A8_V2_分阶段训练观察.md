## E0.1-B 基线对照说明

用户询问的“E0.1-B 512”是 Pilot 的 **512 条训练样本**，该 Pilot 实际训练 128 个 optimizer steps。E0.1-B Pilot Base 在相同 160 条 Pilot Dev 上画像 Micro-F1 为 **0.06484**（TP/FP/FN `13/130/245`，Macro-F1 `0.04427`）；对应 128-step Pilot Adapter 为 **0.00766**（`1/2/257`）。P4048 的 Pilot160 Micro-F1 为 0.34679，高于该 Base 数值；V2 使用独立专项 Prompt 和生成配置，故此处仅作同集背景参照。

项目 E01-B Full Fast-only 在同一 Dev224 Cohort 的既有画像 Micro-F1 为 `0.425787`；P4048 为 `0.44051`，高出该参考值约0.01473。两者任务 Prompt 与生成设置不同，以上比较不替代配对正式评测。所有分数均为本地代理指标，不是官方评分。
