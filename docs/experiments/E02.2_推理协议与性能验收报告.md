## 3. E02.2-A Token ID 核验实现

`scripts/e02_token_equivalence.py` 连接已经运行的 OpenAI-compatible vLLM 服务，最多处理 20 条无标签输入，并默认附加 2 条只含合成文本的 `</think>` 用例。每个请求固定使用 `model=e01-full`、`enable_thinking=false`、`return_token_ids=true` 和 `max_tokens=1`。

本地预期序列通过 `participant.run_inference.prepare_sample_messages()` 走现有 T1 选择，再由 `src.shared.prompting` 使用冻结 P0、原生 roles 和 Chat Template 编码。脚本校验 vLLM CLI 精确版本、本地 Base/Adapter Hash、`/v1/models` 中的 Base 与 Adapter 名称，随后比较服务端响应顶层 `prompt_token_ids` 与本地序列的每个整数。

Manifest 不保存消息正文、生成文本或完整 Token ID 数组。它保存输入/配置/Tokenizer 哈希、样本 ID、序列长度和哈希、逐条是否相等、首个差异位置及最多 7 个 ID 的局部窗口。已有 Run 目录不会覆盖。缺少 `prompt_token_ids`、HTTP 拒绝、格式错误、超时与实际不相等会分成不同状态，不能仅凭 `usage.prompt_tokens` 数相同判通过。

vLLM `0.11.1` 的 [OpenAI API Protocol 文档](https://docs.vllm.ai/en/v0.11.1/api/vllm/entrypoints/openai/protocol/) 声明了 `return_token_ids` 请求字段；[Chat Serving 实现文档](https://docs.vllm.ai/en/v0.11.1/api/vllm/entrypoints/openai/serving_chat/) 显示响应可在该选项启用时返回 `prompt_token_ids`。真实服务仍须运行命令验证字段是否实际可观察。

## 4. E02.2-A GPU 最小核验命令

只在用户的 WSL 环境执行。Terminal 1 启动与 E02.1 Smoke 相同的 Base + Full B LoRA 服务；Terminal 2 运行诊断。该服务仅供有限协议诊断，不调用参赛 Runner。

### Terminal 1：启动固定 vLLM 服务

```bash
cd ~/projects/EmotionalCompany

VLLM_BIN="$HOME/miniforge3/envs/conda_env/bin/vllm"
BASE_DIR="$PWD/participant/model"
ADAPTER_DIR="$PWD/outputs/training/E01-B-FULL-20261028-133805/adapter"
test -x "$VLLM_BIN"
test -f "$BASE_DIR/config.json"
test -f "$ADAPTER_DIR/adapter_config.json"

"$VLLM_BIN" serve "$BASE_DIR" \
  --host 127.0.0.1 \
  --port 8000 \
  --served-model-name model \
  --tensor-parallel-size 1 \
  --gpu-memory-utilization 0.80 \
  --dtype bfloat16 \
  --max-num-seqs 1 \
  --max-num-batched-tokens 2560 \
  --max-model-len 2560 \
  --enable-lora \
  --lora-modules "e01-full=$ADAPTER_DIR" \
  --max-lora-rank 8
```

### Terminal 2：对照 10 条既有无标签样本与 2 条合成样本

```bash
cd ~/projects/EmotionalCompany
source .venv/bin/activate

RUN_ID="E02.2-A-TOKEN-$(date -u +%Y%m%dT%H%M%SZ)"
RUN_ROOT="$PWD/outputs/evaluation/e02/$RUN_ID"

python scripts/e02_token_equivalence.py run \
  --config configs/deployment/e02_vllm_smoke.json \
  --input outputs/evaluation/e02/E02.1-VLLM-FULLB-20261101T070852Z/test_input.jsonl \
  --run-root "$RUN_ROOT" \
  --vllm-bin "$HOME/miniforge3/envs/conda_env/bin/vllm" \
  --base-url http://127.0.0.1:8000/v1

python -m json.tool "$RUN_ROOT/run_manifest.json"
```

看到 `status=passed_exact_server_prompt_ids` 且 `exact_match=12` 后，在 Terminal 1 用 `Ctrl+C` 结束服务。若返回码非零，仍检查并回传 `run_manifest.json`；根据其中 HTTP 状态、字段状态或首个差异位置继续诊断。不要复用同一 Run ID。
