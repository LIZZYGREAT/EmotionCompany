## 3. 指标定义与合成验收结果

- 情绪：固定官方 Schema 的 16 类；空/非法情绪计错，不增加第 17 类。计算 Accuracy、固定 16 类 Macro-F1、逐类 Support/Precision/Recall/F1、16×16 混淆矩阵，并单列无效/空预测诊断列；`zero_division=0`。
- 画像：从提交 Schema 读取 10+12+11 个合法标签。各维度计算集合 Exact Match、Micro P/R/F1、固定标签集合 Macro-F1、空集率、平均标签数及标签级 TP/FP/FN；另报告三维同时 Exact Match 与整体 33 标签 Micro/Macro-F1。
- 回复：SacreBLEU **2.5.1**，Corpus BLEU-4，`tokenize=char`、四阶、指数平滑、`effective_order=true`；ROUGE-L 用 Unicode codepoint LCS，去除全部 Unicode 空白，宏平均样本 F1。空预测保留在分母，ROUGE-L 记 0。
- BERTScore：只接受显式本地模型路径与固定 revision 的离线运行。当前配置关闭且未下载模型，返回 `status=not_run`、原因 `disabled_by_config`、分值 `null`。
- Raw 诊断：严格解析完整原始字符串，拒绝额外文字、代码围栏、重复 JSON key 和非标准 `NaN/Infinity`；再分别检查 A0 字段/标签/非空回复/`memory_refs=[]`。最终提交则独立按官方 Schema 校验。报告不将本地指标换算成赛事分数。

合成端到端验收使用 4 条虚构样本，`dataset_scope=synthetic_fixture`、`backend=mock`，无模型推理或计时。运行 ID 为 `synthetic-e00-1`，实测值：

| 指标 | 结果 |
|---|---:|
| 情绪 Accuracy / 16 类 Macro-F1 | `0.75` / `0.1875` |
| 三维同时画像 Exact Match / 33 标签 Micro-F1 | `0.75` / `0.8` |
| Corpus BLEU-4 / 字符级 ROUGE-L | `58.44493461859005` / `0.75` |
| Raw 严格 JSON / A0 Schema 合法率 | `0.25` / `0.25` |
| 最终 Submission Schema 合法率 | `1.0` |
| BERTScore | `not_run`，值为 `null` |
| 性能 | 未运行；Mock 没有延迟数据 |

Raw 失败样本没有从提交分母中删除：最终结果仍按 4 条计算。评分产物包括机器可读 `metrics.json`、简报 `report.md` 与仅含 ID/错误类型的 `case_errors.jsonl`。

另用真实 D0.3 `smoke_input.jsonl` 执行了 20 行 Mock 闭环：运行 ID `E00.1-mock-smoke-20261026`，评分器未传 `--id-map`，自动读取并校验 `smoke_id_map.jsonl`。Mock helper 只读取无标签推理输入，用固定合法占位 Completion，不读取 References；结果 `execution_mode=mock_fixture`，情绪 Accuracy `0.05`、Raw/Submission Schema 合法率均为 `1.0`，无延迟。该分数只验证真实 Dev Smoke 的对齐和评分流程，不是模型成绩。Train 多数类基线从 D0.3 Train 16,312 条独立计算，标签为 `anxiety`，在这 20 条 Dev Smoke 上 Accuracy 为 `0.1`；Train 缺失时现在会输出 `status=not_run` 且标签/Accuracy 均为 `null`。
