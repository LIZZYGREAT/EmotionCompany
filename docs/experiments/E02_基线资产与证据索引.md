## 4. 恢复核验命令

在仓库根目录、原始忽略目录仍在时，可重新校验历史聚合证据。命令只读原有 Run；新结果写到新的 `outputs/` 子目录，不改训练或评测源产物：

```bash
python3 scripts/e01_b_diagnose.py \
  --training-run-root outputs/training/E01-B-FULL-20261028-133805 \
  --comparison-run-root outputs/evaluation/e01_b/comparison/full-20261029-062541 \
  --output-dir outputs/evaluation/e01_b/diagnostics/e02-baseline-index-check

sha256sum \
  outputs/training/E01-B-FULL-20261028-133805/manifest.json \
  outputs/training/E01-B-FULL-20261028-133805/adapter/adapter_model.safetensors \
  outputs/training/E01-B-FULL-20261028-133805/adapter/adapter_config.json \
  outputs/evaluation/e01_b/comparison/full-20261029-062541/comparison_summary.json
```

脚本只核验和汇总已有证据，不加载模型、训练、推理、重评分，也不导出原始对话。历史源文件不存在时应标为缺失，不能重建或猜测。
