# E00.2 真实模型 Smoke 与解码对照报告

## 结果摘要

E00.2 的真实模型阶段已完成：单样本预检通过；Greedy 与 Sampling 各完成同一组 20 条 Smoke 推理，并分别通过 E00 scorer。`run_manifest.json` 状态为 `real_smoke_scored`。两组使用相同基础模型权重、输入和 P0/F2/T1 配置，结果可审计。

工程验收通过不代表模型质量通过。两组的原始模型输出 A0 Schema 合法率都是 0%，情绪准确率均为 5%；输出归一化后的官方 Submission Schema 合法率为 100%。这组 20 条样本只用于 Smoke 和解码探索，不足以确定 Greedy 或 Sampling 更优，也不支持启动 E00.3。

## 结论与产物

- 真实 Qwen 基础模型、NF4/BF16、CUDA 参数放置、Raw/Submission、20 条 ID 对齐和两组评分均通过，完成了 E00.2 Smoke 工程验收。
- 质量指标较低，Raw A0 合法率为零；当前主要观察是输出格式、标签和画像结构稳定性仍不足。
- Greedy 的 BLEU-4/ROUGE-L 较高；Sampling 的画像 Micro-F1 只高 0.0017，延迟均值更高约 6.1%。样本量和指标差异不足以冻结策略，暂不选定赢家。
- 不运行完整 Dev，不进入 E00.3；后续决策需由更充分的验证计划另行确定。
- Raw 文本、逐样本对照、两组 Performance/Metrics 和 `run_manifest.json` 保存在被 Git 忽略的 `outputs/evaluation/e00_2/E00.2-20261026-220635/`；版本化文档不包含对话内容。
