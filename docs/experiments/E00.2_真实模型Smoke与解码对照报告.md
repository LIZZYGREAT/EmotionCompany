## 用户本机 WSL 执行命令

确保 WSL 仓库 `.venv` 已安装项目和评测依赖，且 `participant/model` 指向已核验的完整本地 snapshot，然后执行以下命令。脚本会先做一条真实 NF4 预检，再按顺序完成 Greedy 与 Sampling 两组 20 条推理、E00 scorer 评分和脱敏对照摘要；每个 run ID 都必须唯一。

```bash
cd ~/projects/EmotionalCompany
source .venv/bin/activate
python scripts/e00_2_smoke.py --run-id "E00.2-$(date +%Y%m%d-%H%M%S)" --execute
```

所有真实 Raw 和逐样本对照只保存在 `outputs/evaluation/e00_2/<run-id>/`（Git 忽略）。如运行成功，应从该目录的 `run_manifest.json`、两组 `performance_report.json`、`metrics.json`、`comparison_summary.json` 和 `comparison_cases.jsonl` 补充后续正式验收记录；不要把真实对话文本复制到版本控制文档。
