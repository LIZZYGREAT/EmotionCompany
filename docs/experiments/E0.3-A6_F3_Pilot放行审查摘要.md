# E03-A6 F3 Pilot：Full 审查摘要（只读）

## 请求审查的结论

**Pilot 综合结论：`inconclusive`。** F3 的解析、Schema、重载和 Fast/完整生成前缀一致性均表现稳定；160 条 Dev 的 Fast 画像预测仍有 98.1% 为空，仅 3/160 条预测出非空画像，未达到训练前冻结的 16/160 门槛。因此本摘要不放行 Full。

**是否值得独立评审 Full：值得。** 同 ID Raw 层画像 TP 从 F2 的 1 提升到 F3 的 5，Micro-F1 从 0.00766 提升到 0.03745；情绪准确率从 43.13% 到 46.25%。32 条 Smoke 的 Fast 画像前缀评测较完整输出少生成 91.4% Token，解析和前缀一致性均为 100%。这些正向信号值得审核是否能通过一项完整训练检验收敛，但不推翻画像稀疏门禁，也不证明 Full 会改善最终质量。

## 必须审核的风险

1. Pilot 训练 Manifest 的 `last_checkpoint` 仍指向已经因 `save_total_limit=2` 被清理的 `checkpoint-32`；当前有效权重文件为 `checkpoint-96` 和 `checkpoint-128`。这不影响已保存 Adapter 与重载结果，但说明检查点轮换后的 Manifest 指针尚未自动更新。
2. 当前 Pilot 恢复代码只实现并验证了 step-32 暂停续跑，以及一次发生在恢复 Trainer 启动前、零 optimizer steps 的明确故障恢复；它尚未证明训练中段失败后可从最近完整 Checkpoint 恢复，也没有 A6 Full Run 的分片落盘、异常恢复和最终结果一致性门禁。
3. 完整 Smoke 的第一次评分曾因错误要求 32 个 Smoke ID 与完整 160 个 References ID 集合完全相等而失败。已从 32 条 fsync 日志恢复评分，原文未重生成；Run Manifest 保留旧错误、评分器修复身份和 `generation_repeated=false`。
4. Fast 画像门禁因非空画像预测仅 3/160 而失败。Smoke 格式和前缀门禁通过不能替代该质量门禁。
