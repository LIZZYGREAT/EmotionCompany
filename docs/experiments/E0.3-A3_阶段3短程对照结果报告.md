# E03-A3 阶段 3 短程对照结果

> 完成日期：2026-11-05。依据已冻结的 224 点 `development_proxy`，对同一 Full B Adapter 初始化的 Control 与 Candidate 各执行 128 步训练和完整生成。阶段结论：`negative_result`，不升级该采样方案。

## 结论

Candidate 多找回了 25 个画像标签 TP，FN 减少 25；同时 FP 增加 116（Control 的 70.3%），画像 Micro-F1 从 Control 的 `0.4012` 降到 `0.3931`，Micro Precision 从 `0.4500` 降到 `0.3628`。画像 Micro-F1 的 95% 会话聚类区间为 `[-0.0585, 0.0434]`，跨过零。短历史组的 Micro-F1 也从 `0.2553` 降到 `0.2154`。

预注册门槛未通过：画像 F1 没有达到 `+0.03`、聚类区间跨零、FP 增幅超过 10%、Precision 下降超过 0.01、短历史画像 F1 下降、情绪 Accuracy 下降 0.0313，且 Control 和 Candidate 都低于 E01-B Full 的同 ID 画像 Micro-F1。Candidate 的严格 JSON/A0 下降 0.0045，回复 BLEU-4 下降 2.39%（在 5% 门槛内），ROUGE-L 上升 2.66%；这些结果不能弥补画像和情绪门槛失败。

Candidate 的训练采样扩大了画像预测量，未形成短历史特异的净收益。Gold 全空的 76 点上，FP 从 43 增至 87；短历史 41 点上，TP 只增加 1，FP 增加 17；长历史 183 点上，TP 增加 24，FP 增加 99。该结果支持停止当前候选，不支持继续按此采样方案扩训。
