Full B 已消除 Pilot 几乎全空画像的现象，但画像仍有明显长尾；`interests` 表现相对较好，`style` Macro-F1 仅 0.1548。D0.3 Dev 的三维 Gold 全空为 660/1,833（36.01%）；恒空预测 Exact Match 为 36.01%，高于 Full B 的 32.08%，但会得到 0 的画像 Micro-F1。Full B 的 Micro-F1 为 0.4223，说明逐标签恢复有明显改进；Exact Match 应与逐维 Recall、Micro/Macro-F1 合看。

情绪方面，Adapter 相对 Base 的正确命中数在 Dev 每个 Gold 类均持平或提升；剩余的典型弱项是 `care=0/6`、`mixed=5/93`。Adapter 混淆较多的方向包括 fear→anxiety、helplessness→anxiety、mixed→anxiety。Raw 层还有 32 次 JSON parse 失败，其中 29 次到达 G=1,200；另有 3 次可解析 JSON 的画像标签超出 A0 枚举。详见[深度诊断报告](../experiments/E0.1-B_Full_深度诊断与证据整理.md)。

质量指标为 `local_proxy`；BERTScore 与官方性能没有运行。本机 Runner 的 100/100 轮统计是本地 Transformers 测量：Base 平均 4.17 秒、Adapter 平均 13.43 秒；它不等于官方部署性能，且生成越长的样本延迟也越高。没有逐样本 BLEU/ROUGE 结果，因此本轮没有计算长度与文本指标的逐样本关系。
