### 2. 我已在原稿中确认的排版问题

## 二、统一正式学术报告的视觉规范

### 1. 视觉定位及颜色

采用**白底、深色正文、低饱和蓝灰主色**的大学课程/竞赛研究报告风格。图表以实用性为主，不加装饰性渐变、阴影、伪 3D、色彩花哨的大卡片。

| 角色 | 建议颜色 | 用途 |
|---|---|---|
| Primary | `#1C3B53` | 章标题、封面重点、关键图元素 |
| Secondary | `#35708D` | 小标题、表头辅助线、当前方法强调 |
| Body | `#20272E` | 正文、公式、表内主要文字 |
| Muted | `#5E6974` | 图注附加信息、页眉、表格来源说明 |
| Divider | `#CBD3DA` | 页眉细线、表格规则线、分隔 |
| Light | `#F1F4F6` | 算法代码块极浅底色 |

**颜色使用规则**：正文用接近黑色，链接在 PDF 中可用主蓝，但打印时也应可读；正文不使用整段蓝色。折线/柱状图需要的系列色在同一图内有清楚的图例、线型或标签区分；打印成灰度也能辨识。

### 2. 字体体系：从 LaTeX 导言区一次修改

当前混合西文字体较明显，建议统一为：

- **中文正文**：`Noto Serif CJK SC`，规整衬线字体。
- **中文标题**：`Noto Sans CJK SC`，中等字重（Semibold 可用则选，不能假造 Font 文件）。
- **英文正文**：首选 `TeX Gyre Termes`，如本机不可用则回退到 `Libertinus Serif` 或保留现有 `Liberation Serif`，并记录实际取用情况。统一标题英文为相容无衬线（如 `TeX Gyre Heros`）；不与默认 Computer Modern 的字型比例反复跳变。
- **数学公式**：优先评估 `unicode-math` + `Latin Modern Math` 或可用的 `STIX Two Math`，测试后决定是否启用。**先用包含粗体向量、下标、\mathcal、\mathbb、长公式的现有正文回归编译**；如会破坏旧公式，保留原数学方案但调整与文字的字号协调。不得同时装载有冲突的数学字体包。
- **代码**：统一 `DejaVu Sans Mono` 或同等级等宽字体；中文说明放在普通正文字体的盒子中，不强制中文使用西文等宽字体。

`ctex` 的 CJK 字体应明确 regular/bold 行为，避免缺字或伪斜体。例如正文不使用中文斜体；英文术语斜体保留。不要把字体文件、操作系统专有字体打包到仓库。

可将上述风格拆出 `report-style.tex`，由 `main.tex` 引用。但若引入新文件会破坏当前工程的快速编译，则直接在导言区维护一组宏即可，**不需要为了模块化制造很多 .sty**。

### 3. 具体页面排版建议

| 项目 | 修改要求 |
|---|---|
| 纸张/边距 | 保留 A4；正文左右约 2.5–2.7 cm，上下约 2.5–2.7 cm；页眉不压正文 |
| 正文字号 | 中文约 11–12 pt（现有 `zihao=-4` 可保留），行距 1.26–1.34；段距不宜同时过大 |
| 章标题 | 收紧至约 18–20 pt，使用无衬线加粗，章号与文字对齐，避免大字号造成一整块留白 |
| 节标题 | 约 14–15 pt；小节标题约 12–13 pt；层级清楚，但不要三级连续占据半页 |
| 摘要 | 维持独立页，关键词与正文关系清楚，摘要不使用彩色大标题或彩色框 |
| 页眉 | 左侧可保留项目短名；右侧优先使用简短章名，过长章名做截断/缩写；页码居中 |
| 表格 | 优先 `booktabs`，减少纵线；数字列右对齐并统一小数位；跨页表可用 `longtable`；图表来源小字放表下注 |
| 代码与 JSON 示例 | 采用浅灰边界的等宽块，确保换行可控，代码不能出页边界；可用 `fvextra` / `fancyvrb`，不要求 `shell-escape` |
| 图题 | “图 4.x 画像专项训练……”等统一中文图题；在图题下提供简短“数据：…”来源（如有），不把长说明堆在图内部 |
| 公式 | 相同字号/数学字体，行间距一致，沿用 `\label` 和 `\eqref`，不让长英文公式/代码越界 |
| 目录 | 缩小过密的目录字体层级，保留章/节/小节必要层级，不列入具体插图待办附录 |

封面建议改为“**竞赛实验研究报告**”清晰标识 + 项目主标题 + 英文技术副标题（可选）+ 队伍/成员/单位/日期。保持纯白、少量细线/浅灰，不制作海报式大字封面。队名、学校、成员仍保留宏作为待填写项，**不能杜撰个人信息**。

### 4. 表格与数字格式统一

- 指标写法固定：`Micro-F1`、`Macro-F1`、`Precision`、`Recall`、`Accuracy`、`BLEU-4`、`ROUGE-L`、`P50/P90/P95`。
- 比例类图中统一采用 0–100% 或 0–1 小数一种口径；表格的当前小数值可以保留，但在表头/图注说明单位。`0.4678` 与 `46.78%` 表达同一个 F1，不能在同一列无说明交替使用。
- 标注 `pp`（百分点）时使用百分比之差，例如 `65.36% - 12.82% = 52.54 pp`；普通 `F1` 差值可用 `+0.0664`。
- 训练步数 `512 / 1024 / 2048 / 4048 / 4504` 是 **Optimizer Step**，不要混写样本数；`512 steps × 4` 才是 2,048 条曝光。
- 宽表格优先调列宽、`\tabcolsep`、`\small` 或拆表；不要全表反复使用 `\resizebox{\textwidth}{!}` 把文字压小。
- 对原文件 `Underfull \hbox` 的行号逐一检查；修复因为极窄列、长文件名或单词无法断行产生的排版问题，不需要为了让日志完全没有任何 Underfull 而扭曲句子。

```text
script | generated_sha256 | verification_status
```

所有正文现成数字**先从仓库的实验报告和可用 JSON/CSV 核对**，核对成功才写入图表数据；实际数据不可取得时，保留对应图位并在交付报告明确列出缺口，不能用模拟数据填充。以上表中已有数字来自**当前 TeX 草稿**，在 Codex 生成最终统计图之前仍需对应实验记录复核。

- 对 10 张图逐一检查：项目名称、节点逻辑、值、单位、来源、文件名、插入后的实际尺寸。

## 五、具体修改主 TeX 的方式

1. **导言区**：清理冲突或重复的字体设置，统一 `ctexset`、`hypersetup`、`captionsetup`、表格和列表。文档继续采用 XeLaTeX；不要强行切换 Word 或 pdfLaTeX。
2. **封面和摘要**：建立统一标题层次，避免所有元素使用大号深蓝粗体；队伍、成员、学校继续使用已有宏。
3. **章节开头**：改善 `chapter` 的 `beforeskip/afterskip` 与章标题字号；给章节第一页留出合理首段空间，但不要故意制造半页空白。
4. **正文中西文混排**：统一命令、模型名、数字、单位和数学字号。当前原稿在低秩训练段落含“**LoRA 应用于注意力投影的 注意力投影矩阵**”的重复表述，允许做类似**显而易见的文字校对**，但不重写实验结论或新增未经验证的数值。
5. **表格**：逐一检查 `tab:tasks`、`tab:dataset-count`、`tab:e01-base`、`tab:explorations`、`tab:a8-trend`、`tab:e03b-training`、`tab:final-profile`、`tab:e03b-replay`、`tab:docker-perf` 及附录来源表；表头一致、宽表能正常换行、行高适中、不跨出页边界。
6. **图位**：按 10 个固定文件名生成图片；检查图片没有被 `\includegraphics[height=<旧占位高>]` 过度缩小。允许根据最终图形纵横比单独调整 `\figureplaceholder` 的第 4 参数（保留 `keepaspectratio`）。
7. **图引用**：正文在相关位置使用“如图~`\ref{fig:...}` 所示”的自然文字引导。原本已经解释充分的不必重复一大段；不要让图片成为没有文字联系的孤立插图。
8. **附录**：保留“实验数据来源与版本说明”；将“待补充插图清单”从最终阅读版移至 `figures/FIGURE_MANIFEST.md`。附录中的来源名能指向仓库真实文档或本地报告，避免仅保留模糊的前缀。
9. **README**：更新编译方式、项目文件结构、重新绘图命令和 PDF 验收命令，写清当前不需要 `--shell-escape`。
10. **保持可复现性**：对原 TeX / 原 PDF 先保存版本；修改之后若出现明显内容数字变化，输出一个逐项差异表并解释具体来源，不能悄悄改动数字。

## 六、建议的 Codex 实施顺序

### 第 1 步：建立事实核对清单（不画图）

- 扫描原 TeX，枚举 10 个图位、全部已有表格与公式；报告现有字体、页面参数、编译日志中的异常。
- 在模型仓库内定位各阶段报告与结果文件。将用于每张图的数据整理成 `figures/data/*.json` 或 CSV；为每项值登记来源。
- 自动检查“每个图的统计数据与原正文表格一致”；如原始报告与原 TeX 不一致，保留原文并提交事实差异记录，优先请用户确认，不自行采用较好看的数字。

### 第 2 步：统一字体和排版，先做少量页面预览

- 修改主 TeX 导言区或 `report-style.tex`；先编译查看封面、章节第一页、典型表格页与公式/代码页。
- **在增加 10 张图片之前**，确认中文/英文/数学字体风格、行距、标题、页眉、段距和表格已经稳定。
- 使用 `pdffonts main.pdf` 检查字体嵌入；从 PDF 渲染实际文字样例，确认字形、粗体、中英混排和数学上下标。不能只看编译退出码。

### 第 3 步：制作全部十张图，逐张核对数据

- 按第三节的图像说明生成 01–10，优先先做 **01、03、04、08** 架构图，再做 02、05、06、07、09、10 统计图。
- 每一图交付：`figures/<id>.pdf`、对应源文件、数据文件（若为统计图）、Manifest 记录。
- 单图预览时检查：标签是否清晰、数字与单位有无错误、绘图比例是否匹配它在 TeX 里的预留高度。

### 第 4 步：整书编译与布局优化

在报告目录下：

```bash
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
pdfinfo main.pdf
pdffonts main.pdf
rg -n 'Overfull|Underfull|Missing character|Undefined control sequence|LaTeX Warning' main.log
```

必要时用 `latexmk -xelatex` 代替两次 XeLaTeX，但要确认当前环境支持。原报告已有使用 `needspace`、`float`、`caption` 等功能，调整浮动布局时**先修真实排版问题，避免到处添加 `\clearpage`、`\vspace` 和硬编码 `\newpage`**。

### 第 5 步：全页视觉验收及内容回归

- 将 PDF 每页渲染为 PNG，制作 contact sheet，**全页检查**；再重点检查目录、章节第一页、所有图所在页、最长表格、附录和最后一页。
- 至少检查两类页面尺寸：正常 A4 全页阅读视角和 100% 放大后的局部正文/图表阅读。保证页眉、图题、表格、代码块和数学公式不重叠、不越界、不出现方框缺字。
- PDF 文本检查：能正常检索/复制中文；不存在未替换的 `待插图`、`figures/*.pdf` 占位框、`??` 引用、残留调试字符串。
- 运行自动脚本核对 10 图文件全部存在、每图 Manifest 有来源、所有图片能被 TeX 引用、正文数值未意外变化。
- 与修改前 PDF 对照关键页面：字体更统一，标题层级更清楚，图片说明不重叠，页码/图表引用连续。
