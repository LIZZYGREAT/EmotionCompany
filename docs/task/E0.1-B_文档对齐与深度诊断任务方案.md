### 2. 事实记录规则

每一条新增结论必须明确区分：

| 证据状态 | 使用条件 |
|---|---|
| `verified_from_local_artifacts` | 实际打开并检查了本机 Run / 评测产物，且身份、数量与哈希校验通过 |
| `reported_in_versioned_doc` | 仅有仓库中的正式验收报告，未重新计算本机原始产物 |
| `derived_from_verified_artifacts` | 有明确公式/脚本及版本，可从已核验产物重新计算 |
| `hypothesis` | 可作为解释线索，当前证据不足以断言因果 |
| `not_run` / `unavailable` | 未执行或相关源文件缺失；明确缺失项与原因 |

不得把版本化报告的文字直接称为“本人已从日志复算”；不得在只读分析脚本缺文件时静默生成 Mock、替代数据或补造结论。
