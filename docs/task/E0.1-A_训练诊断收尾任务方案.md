## 一、任务背景与判定目标

已完成的有效训练 Run 为 `E01-A-20261027-223703`。真实 Qwen3-1.7B NF4 + LoRA 在 8 条 Train 样本上完成 120 次 Optimizer 更新；记录的首 10 步/末 10 步平均 Loss 为 `2.7209 / 0.000388`，末步情绪准确率 `8/8`，Raw A0 Schema 合法率 `8/8`；Adapter 重载与 Base 权重 SHA 校验通过。

同一 Adapter 在 E00.2 的固定 20 条 Dev Smoke 上：情绪 `2/20`、画像标签 Micro-F1 `0`、Raw A0 Schema `7/20`。这是小样本过拟合实验的泛化诊断，不能据此判断正式全量 SFT 的上限。尤其是 **“训练集画像是否学会”尚未在当前报告中单独交代**。本任务只提取已有证据，回答以下问题：

1. 20/40/60/80/100/120 步中，Loss、训练集情绪、画像与 Raw JSON 的走势分别怎样？
2. 最后一步，8 条训练样本的画像标签 Micro-F1、各维度 Precision/Recall/F1、非空标签召回和三维 Exact Match 是多少？
3. 若训练集画像很好、Dev 画像为零，是否由泛化失败/大量预测空集表现出来？若训练集也很差，是否存在标准 Completion-only Loss 被长回复 Token 主导的迹象？以上均为诊断假设，不能直接宣称因果。
4. Dev 的 11 条解析失败与 2 条非法标签是什么结构类型？Base 与 Adapter 的逐 ID 变化有无共同模式？
5. E01-A 是否满足**本来设定的工程验收门槛**，有哪些未被证明的能力？

## 三、具体任务

### 1. 将历史指标按统一口径重建

开发一个小型只读聚合工具（建议 `scripts/e01_a_diagnose.py`），**复用** `src/evaluation/metrics.py` 已有指标函数与 JSON 严格解析规则；不另写第二套 BLEU、ROUGE、Emotion F1 或 Profile F1。

- 验证 `train_log.jsonl` 的 Optimizer Step 唯一、连续、数值有限；按 Step 输出 Loss 表与首末窗口变化，不把训练 Loss 当作 Dev Loss。
- 加载每个 `train_diagnostics_step_*.json`，标注 `scope=train_fitting_only`；检查样本 ID 是否始终等于 `selected_samples.json`。区分训练时计算的指标、训练集生成诊断和 Dev 生成指标。
- 从末步 `profile` 汇总 **Micro-F1、Macro-F1、三维 Exact Match、每个维度的 Precision/Recall/F1**，并检查空集预测率。若现有记录缺少某个统计量，只从已经保留的 Gold 与训练 Raw/Submission 重算；不可从聚合 F1 反推混淆矩阵。
- 与 `step=0` 及中间 Step 对比，展示是否存在训练集预测能力的逐步改善；避免只报告 120 Step 的两个最好看的指标。
- Raw 严格 JSON 可解析率、Raw A0 Schema 合法率、归一化后的 Submission 合法率必须分别输出；其中后者不能用来证明原始生成合规。

### 2. 核对 20 条 Dev Smoke 的模型行为

- 确认 E00.2 Base Greedy 与 E01-A Adapter 的 `id` 集合完全一致（20/20），P0/F2/T1、Tokenizer、Greedy、量化、生成上限和评分口径一致。
- 对每条 ID 对齐 Gold emotion、Base 预测、Adapter 预测、解析状态、Gold/预测画像非空维度；生成 **ID-only 或匿名索引** 差异表，禁止写入跟踪文档的对话正文与 Raw 回复。
- 分别统计 Base/Adapter 的情绪预测类别分布、Gold 类别支持量、混淆矩阵；不要从 20 条推断总体统计显著性。
- 将 Dev 画像分析拆分为：Gold 非空样本数、预测非空样本数、非空标签命中数、每维 Recall、预测全空比例；说明为什么三维 Exact Match 可以提高而 Micro-F1 为零。
- 对 `parse_failure` 分类：不是 JSON 对象开头、JSON 尾部额外文本、控制字符、括号/引号错误等；仅在有真实 Raw 证据时计数，未知原因标 `unknown`。
- 检查生成的 EOS/长度分布以及 Prompt overflow 数量，排除将停止条件问题误认为分类问题。

### 3. 审查现有验收报告的结论边界

更新 `docs/experiments/E01-A_训练可学习性验收报告.md` 的末尾，新增“训练集画像诊断”和“Dev 小样本局限”两节；保留历史观测值与 Run ID，不覆盖原报告。

| 维度 | 判定要求 |

| 画像训练集拟合 | 必须单列真实指标；不得凭 Loss 推断 |
