## 1. 数据、Prompt 与 Tokenizer

- D0.3 版本：`D0.3-v1`；样本数：Train 16,312 / Dev 1,833 / Val 2,354，合计 20,499。
- D0.3 三份规范化文件均与 Manifest SHA-256 一致：True。
- P0：`P0`，SHA-256 `d427e4996d0075a3adfe03ae25881d093687a6565f5b037f605accecc84c70b2`；标签枚举与 Train/Val 官方 target schema 及顺序一致。
- Tokenizer：`Qwen/Qwen3-1.7B` revision `70d244cc86ccca08cf5af4e1e306ecf908b1ad5e`，类 `Qwen2Tokenizer`；Chat Template SHA-256 `a55ee1b1660128b7098723e0abcd92caa0788061051c62d51cbe87d9cf1974d8`。
- 模板参数：F2 原生消息，`enable_thinking=False`；前缀门禁已在逐样本统计和 16 条标量/批量对照中检查。
- Qwen 模板会解析 assistant 文本中的字面 `</think>`；历史 assistant 消息和目标 JSON 显式带空 `reasoning_content` 字段，防止模板改写原文，字段本身不进入序列。
- 数据 Schema 检查：Train/Val 目标枚举一致；提交 Schema 额外允许空情绪哨兵 `['']`，P0 仍要求一个实际情绪标签。
- 分位数采用 nearest-rank：排序后索引 `ceil(p*n)-1`；所有长度均为真实 Tokenizer Token 数，字符数只用于明确标注的历史保留代理指标。

## 4. 关键比较与限制

- 默认探索前沿 S2048/P1536 与 S4096/P3584 同时改变了 S 和 P，只能作为联合预算对照，不可解释成 S 的单独因果效应。
- 联合前沿的平均消息保留代理比例变化：+8.64%；这里只描述 T1 历史保留，不表示分类/回复质量提升。
- 两个前沿可用率分别为 97.80% 和 99.16%。
- 同 P 的 S2048 与 S4096 对照用于隔离训练总预算影响；固定 P 下 T1 选择相同，主要差异应体现在完整监督是否容纳。
- default_joint_frontier_S2048_P1536_vs_S4096_P3584：平均额外保留历史消息 +1.665，4444 条样本保留更多历史；非空画像样本中 20.38% 保留了更多历史。这是同时改变 S/P 的联合预算差异。
- matched_P1024_S2048_vs_S4096：T1 选择已逐样本验证相同；平均额外保留历史消息 +0.000，额外保留历史样本 0。
- matched_P1280_S2048_vs_S4096：T1 选择已逐样本验证相同；平均额外保留历史消息 +0.000，额外保留历史样本 0。
- matched_P1536_S2048_vs_S4096：T1 选择已逐样本验证相同；平均额外保留历史消息 +0.000，额外保留历史样本 0。
- 推理约束为 P+G≤K。当前参考配置 max_new_tokens=1200 仅作 G 参考；K=[]，状态：`not_assessable_K_unconfigured`。S 与 K 不等同。
- 本阶段没有模型权重加载、训练、Loss Mask、Padding 张量、质量对照或硬件吞吐/显存结论。
