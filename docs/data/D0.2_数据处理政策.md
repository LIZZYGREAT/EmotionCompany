# D0.2 数据处理政策

> 政策版本：D0.2-v1　|　依据：D0.1 原始数据质量审计　|　制定日期：2026-10-24

## 1. 范围与输入基线

本政策规定官方 Train 的预测点隔离、精确监督去重及 Train/Dev 分组边界，并规定官方 Val 的保留方式。只读取原始数据，不改写对话、标签、画像、记忆引用或轮次顺序；本阶段不生成模型 Token、Chat Template 或训练掩码。

## 2. 决策规则

| 情形 | 决策 | 范围及依据 |
|---|---|---|
| 目标/回复引用缺失、歧义、角色不符，或回复数组下标不晚于目标 | 隔离该预测点并记录原因、行号和点索引；不改 ID、不排序、不移动轮次，也不删除整段对话 | 确定性关联错误；D0.1 当前仅有 4 个 `RESPONSE_NOT_AFTER_TARGET` |
| Train 合法历史和完整 Target 完全相同 | 精确保留来源顺序中最早的一份，其余预测点记为重复并映射到代表样本 | 规范 JSON 的值相等才去重；不只比较回复或情绪；不做文本归一化或语义去重 |
| 同一历史但 Target 不同 | 保留所有监督并记录同输入多目标复核信息；禁止自动择一 | 不因回复或标注不同推测哪一项正确。D0.1 未发现此类历史冲突 |
| 完整 turns 重复或合法历史重复 | 作为 Train/Dev 分组约束；不因整段对话重复而整体删除 | 避免关联样本跨集合泄漏。D0.1 发现 202 个额外重复对话记录（202 组、404 条记录），与预测点去重分别统计 |
| 同一原始对话内的其他合法预测点 | 独立保留和判定 | 不因该对话中某一点无效而丢弃同对话其他点 |
| Val 中的合法点 | 全部保留，按同一规则规范化字段；不去重、不参与 Train/Dev 划分 | Val 是官方验证集，不做训练式清洗 |
| 回复长度小于 5 个 Unicode 字符 | 保留并标为复核候选，不按长度过滤 | Train 48、Val 4；对 Train 确定性抽样 12 点，均为合法非空字符串，且与所引用 assistant 轮次完全一致；无控制/替换字符 |
| 空 prediction_points | 不生成样本，保留在来源统计和处理账目中 | Train 5 段、Val 0 段；属于合法无监督对话 |
| 空画像、类别不均衡、非空 memory_refs | 原样保留；不补画像、不重采样、不改权重、不删除记忆引用 | Train 三维全空画像 6,834 点、非空 memory_refs 18,220 点；均是合法监督信息 |
| 文本空白、标点、表情及其他 Unicode 内容 | 原样保留 | 不改写、裁剪、统一标点、去表情或折叠空白 |

## 3. D0.1 问题核对

### 3.1 四个时序异常

逐项按官方数组位置和角色核对；引用回复均与该 assistant 轮次正文完全相同，但该轮位于目标 user 之前且相邻。正文一致不能使错误时序变合法，因此只隔离对应预测点，不试图猜测正确回复或重排数据。

### 3.2 重复和冲突

D0.1 报告 202 个完整 turns 重复额外记录，均按来源记录保留以便审计和关联分组。另有 508 个重复预测点出现次数；这些点都属于上述重复对话记录。抽样核对 12 组后，合法历史和完整 Target 均逐值相同。全量 D0.1 指纹统计的重复预测点组均为二元组；4 个时序异常点各自为单例，不与这 508 个重复出现重叠。因此 D0.3 先隔离 4 点，再对剩余精确监督去重，预期移除 508 个重复点，最终以管线账本为准。

D0.1 未发现相同合法历史对应不同 Target 的组，也未发现 Train/Val 历史或完整对话重叠。分组阶段仍会基于原始 role/content 再次验证边界；如发现跨 Train/Val 重合，停止自动构建并报告，不修改 Val。

### 3.3 短回复与保留项

Train 48 个短回复候选中按来源顺序间隔抽取 12 个检查：12/12 为合法字符串，均与其引用的 assistant 轮次逐字一致；未见控制字符或替换字符。其余短回复仍保留为复核候选，D0.3 记录数量但不按短度处理。

空画像和不均衡标签属于合法数据；例如 Train `surprise` 仅 64 点，仍保留全部类别。`memory_refs` 的非空引用亦完整保留。处理不涉及标签映射、合并或语义判断。

## 4. 复核状态与执行边界

无阻断项。短回复候选继续作为非阻断复核提示；同输入异目标、结构无效引用及跨集合重复均须在 D0.3 再次检查，若出现未在 D0.1 基线中的情况，不静默修复或丢弃。

本政策明确允许的自动变更只有：隔离有确定性引用错误的单个 Train 预测点、精确去除重复 Train 监督中的后续副本，以及将关联组分配到 Train 或 Dev。原始 Train/Val 和 Val 样本不变。D0.4 Tokenizer、截断、Prompt 模板、SFT 标签掩码及训练不在本政策范围内。
